# Retail-Sales-data-analysis

<SQL & Power BI project> 
analyzing retail sales data — from data cleaning and querying in SQL Server to an interactive Power BI dashboard. **(Work in progress)**

## About the Project
This project explores a retail sales dataset covering customers, products, employees, cities, and countries. 
The goal is to clean and query the data using SQL, then build an interactive Power BI dashboard to visualize sales trends, 
top-performing products, and regional performance.

## Tools Used
- SQL Server Management Studio (SSMS) — data cleaning & querying
- Power BI Desktop — dashboard & visualization
